How the ensemble decides

01 · RULES

Explainable signals

Seven lexicon and style detectors (clickbait, sourcing, hype, repetition…) plus a domain check produce the rule score.

02 · MODELS

Two text classifiers

Words, bigrams and style tokens are hashed into 131,072 features. Naive Bayes and AdaGrad Logistic Regression each learn from the labelled examples.

03 · STACKING

Meta-learner

A logistic meta-learner, fitted on out-of-fold predictions, learns how much to trust each model and outputs a calibrated fake probability.

Accuracy is measured with stratified k-fold cross-validation: every number above comes from examples the model did not see while training. The built-in dataset is small and hand-written, so treat its scores as a demo. Train on a public dataset below for real-world numbers.

Train with your own dataset

Upload a labelled CSV, TSV or JSON file. Training runs on the active engine with cross-validation, then replaces the current model. Your file is read in the browser; only the mapped text and labels are sent to the engine.

3 · TRAIN

Works with public datasets such as Fake and Real News (add Fake.csv as “all fake” and True.csv as “all real”), WELFake, LIAR, the Deceptive Opinion Spam corpus (deceptive / truthful) and the Fake Reviews dataset (CG / OR labels). In browser mode large models may not fit in local storage; run node server.js to keep them.

REST API

Start the backend with node server.js (or npm start). The website and these JSON endpoints are served from http://localhost:5510.

GET/api/healthEngine status and a summary of both models
GET/api/modelFull metrics: accuracy, F1, AUC, confusion matrix, top features
POST/api/analyze/newsAnalyse { title, text, url }
POST/api/analyze/reviewAnalyse { text, rating, verified, product }
POST/api/analyze/batchUp to 500 inputs: { type, inputs: [...] }
POST/api/feedbackTeach the model: { type, input, label: "fake" | "real" }
POST/api/trainRetrain: { type, rows: [{ text, label }], includeSeed }
POST/api/resetBack to the built-in model: { type }
# analyse a headline from the command line
curl -X POST http://localhost:5510/api/analyze/news \
  -H "Content-Type: application/json" \
  -d '{"title":"Miracle fruit melts belly fat overnight, doctors shocked"}'
